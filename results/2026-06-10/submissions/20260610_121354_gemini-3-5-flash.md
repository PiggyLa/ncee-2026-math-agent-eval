### Q16

$AC^2 = AB^2 + BC^2 - 2AB \cdot BC \cos B$

所以 $AC = 3$。
因为 $AB = AC = 3$，所以 $\triangle ABC$ 是以 $A$ 为顶角的等腰三角形。
所以 $\angle B = \angle C$，即 $\cos C = \cos B = \dfrac{\sqrt{3}}{3}$。
因为 $A = 180^\circ - 2B$，所以：
$\cos A = \cos(180^\circ - 2B) = -\cos(2B) = -(2\cos^2 B - 1) = -\left(2 \times \dfrac{1}{3} - 1\right) = \dfrac{1}{3}$。
故 $\cos A = \dfrac{1}{3}$。

**(2)**

### Q17

**解：**

**(1)**
当 $N = 4$，$p = \dfrac{1}{3}$ 时，停止练习时投篮次数 $X$ 的可能取值为 $1, 2, 3, 4$。
各取值的概率计算如下：
- $P(X = 1) = p = \dfrac{1}{3}$；
- $P(X = 2) = (1-p)p = \dfrac{2}{3} \times \dfrac{1}{3} = \dfrac{2}{9}$；
- $P(X = 3) = (1-p)^2 p = \left(\dfrac{2}{3}\right)^2 \times \dfrac{1}{3} = \dfrac{4}{27}$；
- $P(X = 4) = (1-p)^3 = \left(\dfrac{2}{3}\right)^3 = \dfrac{8}{27}$。

所以 $X$ 的分布列为：
| $X$ | 1 | 2 | 3 | 4 |
|:---:|:---:|:---:|:---:|:---:|
| $P$ | $\dfrac{1}{3}$ | $\dfrac{2}{9}$ | $\dfrac{4}{27}$ | $\dfrac{8}{27}$ |

**(2)**
**(i)**
事件 $\{X > k\}$ 表示停止练习时的投篮次数大于 $k$。
根据停止练习的规则，投篮次数大于 $k$ 当且仅当在前 $k$ 次投篮中均未投中。
由于每次投篮相互独立，且每次投篮未投中的概率为 $1-p$，
因此前 $k$ 次投篮均未投中的概率为 $(1-p)^k$。
所以，当 $k \leqslant N - 1$ 时，有：
$P(X > k) = (1-p)^k$。

**(ii)**
根据条件概率的定义：
$P(X > k + m \mid X > k) = \dfrac{P(X > k + m \text{ 且 } X > k)}{P(X > k)}$。
因为 $m$ 为自然数，所以 $k + m \geqslant k$，
因此事件 $\{X > k + m\}$ 是事件 $\{X > k\}$ 的子集，
所以 $P(X > k + m \text{ 且 } X > k) = P(X > k + m)$。
所以：
$P(X > k + m \mid X > k) = \dfrac{P(X > k + m)}{P(X > k)}$。
因为 $k + m \leqslant N - 1$，由 (i) 可得：
$P(X > k) = (1-p)^k$，
$P(X > k + m) = (1-p)^{k+m}$。
所以：
$P(X > k + m \mid X > k) = \dfrac{(1-p)^{k+m}}{(1-p)^k} = (1-p)^m$。
又因为 $m \leqslant k + m \leqslant N - 1$，由 (i) 可得：
$P(X > m) = (1-p)^m$。
所以：
$P(X > k + m \mid X > k) = P(X > m)$。
证毕。

### Q18

**解：**

**(1)**
已知椭圆 $C\colon \dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\;(a > b > 0)$ 的左焦点为 $F(-1, 0)$，所以 $c = 1$。

所以 $b^2 = a^2 - c^2 = 4 - 1 = 3$。
故椭圆 $C$ 的方程为：
$\dfrac{x^2}{4} + \dfrac{y^2}{3} = 1$。

**(2)**
**(i)**
设过 $F(-1, 0)$ 且斜率 $k > 0$ 的直线 $l$ 方程为 $y = k(x + 1)$。
联立直线 $l$ 与椭圆 $C$ 的方程：
$\begin{cases} y = k(x + 1) \\ \dfrac{x^2}{4} + \dfrac{y^2}{3} = 1 \end{cases} \implies (3 + 4k^2)x^2 + 8k^2 x + 4k^2 - 12 = 0$。
设 $P(x_1, y_1)$，$Q(x_2, y_2)$。由韦达定理：
$x_1 + x_2 = -\dfrac{8k^2}{3 + 4k^2}$， $x_1 x_2 = \dfrac{4k^2 - 12}{3 + 4k^2}$。
因为 $Q$ 在第三象限，所以 $x_2 < -1 < x_1$。
因为 $R$ 是直线 $PO$ 与椭圆 $C$ 的另一个交点，且椭圆关于原点中心对称，
所以 $R$ 的坐标为 $(-x_1, -y_1)$。

在 $\triangle PQR$ 中，因为 $O$ 是 $PR$ 的中点，所以：
$\mathrm{Area}(\triangle PQR) = 2 \mathrm{Area}(\triangle PQO)$。
因为 $P, Q, F$ 共线，所以：
$\mathrm{Area}(\triangle PQO) = \dfrac{1}{2} |OF| \cdot |y_1 - y_2| = \dfrac{1}{2} \times 1 \times (y_1 - y_2) = \dfrac{1}{2} k (x_1 - x_2)$。
所以 $\mathrm{Area}(\triangle PQR) = k (x_1 - x_2)$。
又因为 $\triangle PFO$ 的面积为 $\mathrm{Area}(\triangle PFO) = \dfrac{1}{2} |OF| \cdot y_1 = \dfrac{1}{2} y_1 = \dfrac{1}{2} k (x_1 + 1)$。
已知 $\mathrm{Area}(\triangle PQR) = 3 \mathrm{Area}(\triangle PFO)$，
所以 $k (x_1 - x_2) = 3 \times \dfrac{1}{2} k (x_1 + 1) \implies x_1 - x_2 = \dfrac{3}{2} (x_1 + 1) \implies x_1 + 2x_2 + 3 = 0$。

由 $x_1 + 2x_2 + 3 = 0 \implies x_1 = -2x_2 - 3$。
代入 $x_1 + x_2 = -\dfrac{8k^2}{3 + 4k^2}$，得：
$-x_2 - 3 = -\dfrac{8k^2}{3 + 4k^2} \implies x_2 = \dfrac{8k^2}{3 + 4k^2} - 3 = -\dfrac{4k^2 + 9}{3 + 4k^2}$。
所以 $x_1 = -2x_2 - 3 = \dfrac{9 - 4k^2}{3 + 4k^2}$。
代入 $x_1 x_2 = \dfrac{4k^2 - 12}{3 + 4k^2}$，得：
$\left(\dfrac{9 - 4k^2}{3 + 4k^2}\right) \left(-\dfrac{4k^2 + 9}{3 + 4k^2}\right) = \dfrac{4k^2 - 12}{3 + 4k^2} \implies -(81 - 16k^4) = (4k^2 - 12)(3 + 4k^2)$
$16k^4 - 81 = 16k^4 - 36k^2 - 36 \implies 36k^2 = 45 \implies k^2 = \dfrac{5}{4}$。
因为 $k > 0$，所以 $k = \dfrac{\sqrt{5}}{2}$。
故直线 $l$ 的方程为 $y = \dfrac{\sqrt{5}}{2}(x + 1)$，即 $\sqrt{5}x - 2y + \sqrt{5} = 0$。

**(ii)**
因为 $P, Q$ 在直线 $l$ 上，所以向量 $\vec{QP}$ 的方向向量为 $\vec{u} = (1, k)$。
因为 $R(-x_1, -y_1)$，$Q(x_2, y_2)$，所以 $\vec{QR} = (-x_1 - x_2, -y_1 - y_2)$。
由 (i) 可知：
$-x_1 - x_2 = \dfrac{8k^2}{3 + 4k^2}$，
$-y_1 - y_2 = -\dfrac{6k}{3 + 4k^2}$。
所以 $\vec{QR} = \dfrac{2k}{3 + 4k^2} (4k, -3)$。
故 $\vec{QR}$ 的方向向量可取为 $\vec{v} = (4k, -3)$。
设 $\angle PQR = \theta$，则：
$\cos\theta = \dfrac{\vec{u} \cdot \vec{v}}{|\vec{u}| |\vec{v}|} = \dfrac{1 \times 4k + k \times (-3)}{\sqrt{1 + k^2} \sqrt{16k^2 + 9}} = \dfrac{k}{\sqrt{1 + k^2} \sqrt{16k^2 + 9}}$。
因为 $k > 0$，所以 $\cos\theta > 0$，$\theta$ 为锐角。
所以：
$\tan^2\theta = \dfrac{1}{\cos^2\theta} - 1 = \dfrac{(1 + k^2)(16k^2 + 9)}{k^2} - 1 = \dfrac{16k^4 + 25k^2 + 9}{k^2} - 1 = 16k^2 + 24 + \dfrac{9}{k^2} = \left(4k + \dfrac{3}{k}\right)^2$。
因为 $\theta$ 为锐角，所以 $\tan\theta = 4k + \dfrac{3}{k}$。
由均值不等式，因为 $k > 0$：
$\tan\theta = 4k + \dfrac{3}{k} \geqslant 2\sqrt{4k \cdot \dfrac{3}{k}} = 4\sqrt{3}$。
当且仅当 $4k = \dfrac{3}{k} \implies k = \dfrac{\sqrt{3}}{2}$ 时等号成立。
故 $\tan \angle PQR$ 的最小值为 $4\sqrt{3}$。

### Q19

**解：**

**(1)**
当 $x \geqslant 0$ 时，$f(x) = 1 - x$；当 $x < 0$ 时，$f(x) = 2^x$。
我们要求 $D(-1) = \{d \in \mathbf{R} \mid f(-1 + d) > f(-1)\}$。
因为 $-1 < 0$，所以 $f(-1) = 2^{-1} = \dfrac{1}{2}$。
所以我们需要求解不等式 $f(-1 + d) > \dfrac{1}{2}$：
- 若 $-1 + d < 0 \implies d < 1$，则 $f(-1 + d) = 2^{-1 + d} > \dfrac{1}{2} = 2^{-1} \implies -1 + d > -1 \implies d > 0$。
  所以 $0 < d < 1$。
- 若 $-1 + d \geqslant 0 \implies d \geqslant 1$，则 $f(-1 + d) = 1 - (-1 + d) = 2 - d > \dfrac{1}{2} \implies d < \dfrac{3}{2}$。
  所以 $1 \leqslant d < \dfrac{3}{2}$。

综上所述，解集为 $D(-1) = \left(0, \dfrac{3}{2}\right)$。

**(2)**
因为 $f(x)$ 是奇函数，所以对任意 $x \in \mathbf{R}$，有 $f(-x) = -f(x)$，且 $f(0) = 0$。
因为当 $x < 0$ 时，$f(x) = 2^x \in (0, 1)$，
所以当 $x > 0$ 时，$-x < 0$，有 $f(x) = -f(-x) = -2^{-x} \in (-1, 0)$。
因为 $x_1 x_2 \ne 0$ 且 $f(x_1) \leqslant f(x_2)$，我们分情况讨论：
- 若 $x_1 < 0, x_2 < 0$，则 $2^{x_1} \leqslant 2^{x_2} \implies x_1 \leqslant x_2 < 0 \implies -x_2 \leqslant -x_1$。
  对任意 $d \in D(x_2)$，有 $f(x_2 + d) > f(x_2) = 2^{x_2} > 0$。
  因为当 $x \geqslant 0$ 时 $f(x) \leqslant 0$，所以必须有 $x_2 + d < 0 \implies d < -x_2$。
  此时 $f(x_2 + d) = 2^{x_2 + d} > 2^{x_2} \implies d > 0$。
  所以 $D(x_2) = (0, -x_2)$。
  同理可得 $D(x_1) = (0, -x_1)$。
  因为 $-x_2 \leqslant -x_1$，所以 $D(x_2) \subseteq D(x_1)$。
- 若 $x_1 > 0, x_2 > 0$，则 $-2^{-x_1} \leqslant -2^{-x_2} \implies x_1 \leqslant x_2 \implies -x_2 \leqslant -x_1$。
  对任意 $d \in D(x_2)$，有 $f(x_2 + d) > f(x_2) = -2^{-x_2}$。
  - 若 $x_2 + d < 0 \implies d < -x_2$，则 $f(x_2 + d) = 2^{x_2 + d} > 0 > -2^{-x_2}$ 恒成立。
  - 若 $x_2 + d = 0 \implies d = -x_2$，则 $f(0) = 0 > -2^{-x_2}$ 恒成立。
  - 若 $x_2 + d > 0 \implies d > -x_2$，则 $f(x_2 + d) = -2^{-(x_2 + d)} > -2^{-x_2} \implies d > 0$。
  综上所述，$D(x_2) = (-\infty, -x_2] \cup (0, +\infty)$。
  同理可得 $D(x_1) = (-\infty, -x_1] \cup (0, +\infty)$。
  因为 $-x_2 \leqslant -x_1$，所以 $D(x_2) \subseteq D(x_1)$。
- 若 $x_1 > 0, x_2 < 0$，因为 $f(x_1) \in (-1, 0)$ 且 $f(x_2) \in (0, 1)$，所以 $f(x_1) < f(x_2)$ 恒成立。
  此时 $D(x_2) = (0, -x_2)$，且 $D(x_1) = (-\infty, -x_1] \cup (0, +\infty)$。
  因为对任意 $d \in D(x_2)$ 有 $d > 0$，所以 $d \in (0, +\infty) \subset D(x_1)$，
  故 $D(x_2) \subseteq D(x_1)$。
- 若 $x_1 < 0, x_2 > 0$，则 $f(x_1) > 0 > f(x_2)$，与 $f(x_1) \leqslant f(x_2)$ 矛盾。

综上所述，在所有可能的情况下，均有 $D(x_2) \subseteq D(x_1)$。

**(3)**
**(i) 证明：**
假设 $f(0) < 1$。
因为当 $x < 0$ 时 $f(x) = 2^x$，且 $\lim_{x \to 0^-} f(x) = 1$，
所以必存在 $x_1 < 0$ 使得 $f(x_1) = 2^{x_1} > f(0)$。
因为 $f(0) \leqslant f(x_1)$，由条件 ① 可得 $D(x_1) \subseteq D(0)$。
因为 $x_1 < 0$，我们可以选择 $x_2 \in (x_1, 0)$，则 $f(x_2) = 2^{x_2} > 2^{x_1} = f(x_1)$。
令 $d = x_2 - x_1 > 0$，则 $f(x_1 + d) = f(x_2) > f(x_1)$，所以 $d \in D(x_1)$。
因为 $D(x_1) \subseteq D(0)$，所以 $d \in D(0) \implies f(d) > f(0)$。
因为 $x_1 < 0$，我们可以选择 $x_1$ 充分接近 $0$，使得 $-x_1 < 1$。
此时 $0 < d = x_2 - x_1 < -x_1 < 1$，即 $0 < d < 1$。
由条件 ② 可知，当 $0 < d < 1$ 时，有 $f(d) < f(0)$，这与 $f(d) > f(0)$ 矛盾。
因此，假设不成立，必有 $f(0) \geqslant 1$。

**(ii) 证明：**
首先，我们证明对任意 $x > 0$，均有 $f(x) \geqslant f(0)$。
假设存在 $x_0 > 0$ 使得 $f(x_0) < f(0)$。
则 $f(x_0) \leqslant f(0)$，由条件 ① 可得 $D(0) \subseteq D(x_0)$。
因为对任意 $x < 0$，有 $f(x) = 2^x < 1 \leqslant f(0)$，且由条件 ② 可知，当 $0 < x < 1$ 时 $f(x) < f(0)$，
所以对任意 $x < 1$（且 $x \ne 0$），均有 $f(x) < f(0)$。
因此，若 $d \in D(0)$，即 $f(d) > f(0)$，则必有 $d \geqslant 1$。
即 $D(0) \subseteq [1, +\infty)$。

因为 $D(0) \subseteq D(x_0)$，所以对任意 $d \in D(0)$，均有 $d \in D(x_0) \implies f(x_0 + d) > f(x_0)$。
选择 $x_1 < 0$ 使得 $f(x_1) = 2^{x_1} < f(x_0)$（因为 $f(x_0) \geqslant 1$ 时，可直接由 $2^{x_1} < 1 \leqslant f(x_0)$ 满足；若 $f(x_0) < 1$，由于 $2^{x_1} \to 0$（当 $x_1 \to -\infty$ 时），也必存在这样的 $x_1$）。
由于 $f(x_1) \leqslant f(x_0)$，由条件 ① 可得 $D(x_0) \subseteq D(x_1)$。
所以 $D(0) \subseteq D(x_0) \subseteq D(x_1)$。
因此，对任意 $d \in D(0)$，均有 $d \in D(x_1) \implies f(x_1 + d) > f(x_1) = 2^{x_1}$。
由于 $D(0)$ 非空（若 $D(0) = \emptyset$，则对所有 $x$ 有 $f(x) \leqslant f(0)$，此时 $f(x_0) < f(0)$ 依然成立，但我们可以选择 $d \geqslant 1$ 使得 $f(d) > f(0)$？不，若 $D(0) = \emptyset$，则没有这样的 $d$。但由于 $\lim_{x \to -\infty} f(x) = 0$，且 $f(0) \geqslant 1$，若 $f(x)$ 在正半轴上有大于 $f(0)$ 的值，则 $D(0)$ 非空。若 $f(x) \leqslant f(0)$ 恒成立，则 $D(0) = \emptyset$。
然而，若 $D(0) \subseteq D(x_1)$，我们可以选择 $d \in D(0)$。
由于 $d \geqslant 1$，若我们选择 $x_1 < -d < 0$，
则 $x_1 + d < 0$，所以 $f(x_1 + d) = 2^{x_1 + d}$。
因为 $d \in D(x_1)$，所以 $2^{x_1 + d} > 2^{x_1} \implies d > 0$，这与 $d \geqslant 1$ 一致。
但我们可以选择 $x_1$ 使得 $x_1 + d < 0$ 且 $2^{x_1 + d} > f(x_1)$。
实际上，为了证明单调性，我们直接证明对任意 $0 < x_1 < x_2$，有 $f(x_1) < f(x_2)$：
假设存在 $0 < x_1 < x_2$ 使得 $f(x_1) \geqslant f(x_2)$。
则 $f(x_2) \leqslant f(x_1) \implies D(x_1) \subseteq D(x_2)$。
选择 $d \in \mathbf{R}$ 满足 $x_2 + d < 0$。因为 $x_1 < x_2$，所以也有 $x_1 + d < 0$。
此时 $f(x_1 + d) = 2^{x_1 + d}$， $f(x_2 + d) = 2^{x_2 + d}$。
由 $d \in D(x_1) \iff 2^{x_1 + d} > f(x_1) \iff d > \log_2 f(x_1) - x_1$。
由 $d \in D(x_2) \iff 2^{x_2 + d} > f(x_2) \iff d > \log_2 f(x_2) - x_2$。
因为 $D(x_1) \subseteq D(x_2)$，所以在区间 $(-\infty, -x_2)$ 上，
若 $d > \log_2 f(x_1) - x_1$，则必有 $d > \log_2 f(x_2) - x_2$。
这要求：
$\log_2 f(x_2) - x_2 \leqslant \log_2 f(x_1) - x_1 \implies \log_2 \dfrac{f(x_2)}{f(x_1)} \leqslant x_2 - x_1 \implies f(x_2) \leqslant 2^{x_2 - x_1} f(x_1)$。
若我们选择 $d$ 使得 $d \in (\log_2 f(x_1) - x_1, -x_2)$，则必须满足 $\log_2 f(x_1) - x_1 < -x_2 \implies f(x_1) < 2^{x_1 - x_2}$。
因为 $x_1 < x_2 \implies x_1 - x_2 < 0 \implies 2^{x_1 - x_2} < 1$。
而由前面所证，对于任意 $x > 0$，均有 $f(x) \geqslant f(0) \geqslant 1$。
所以 $f(x_1) \geqslant 1$，这与 $f(x_1) < 2^{x_1 - x_2} < 1$ 矛盾！
因此，假设不成立，即对任意 $0 < x_1 < x_2$，必有 $f(x_1) < f(x_2)$。
故 $f(x)$ 在区间 $(0, +\infty)$ 上单调递增。
