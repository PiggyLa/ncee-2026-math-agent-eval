### Q15

**(1) 证明 $DE \parallel$ 平面 $BCC_1B_1$：**
在 $\triangle ABC_1$ 中，因为 $D$ 是 $AB$ 的中点，$E$ 是 $AC_1$ 的中点，所以 $DE$ 是 $\triangle ABC_1$ 的中位线。
因此，$DE \parallel BC_1$。
又因为 $BC_1 \subset$ 平面 $BCC_1B_1$，$DE \not\subset$ 平面 $BCC_1B_1$，
所以 $DE \parallel$ 平面 $BCC_1B_1$。

**(2) 求直线 $DE$ 到平面 $BCC_1B_1$ 的距离：**
以 $C$ 为坐标原点，分别以 $CA, CB, CC_1$ 所在直线为 $x, y, z$ 轴，建立空间直角坐标系。
设 $AC = BC = a$。则各点坐标为：
$C(0,0,0)$，$A(a,0,0)$，$B(0,a,0)$，$C_1(0,0,2)$。
因为 $D, E$ 分别为 $AB, AC_1$ 的中点，所以 $D(\frac{a}{2}, \frac{a}{2}, 0)$，$E(\frac{a}{2}, 0, 1)$。
从而 $\overrightarrow{DE} = (0, -\frac{a}{2}, 1)$。
平面 $ACC_1A_1$ 即为 $xOz$ 平面，其法向量为 $\vec{n} = (0,1,0)$。
由直线 $DE$ 与平面 $ACC_1A_1$ 所成的角为 $45^\circ$，可得：
$$ \sin 45^\circ = \frac{|\overrightarrow{DE} \cdot \vec{n}|}{|\overrightarrow{DE}| |\vec{n}|} = \frac{|-\frac{a}{2}|}{\sqrt{0 + \frac{a^2}{4} + 1} \cdot 1} = \frac{a}{\sqrt{a^2+4}} $$
即 $\frac{a}{\sqrt{a^2+4}} = \frac{\sqrt{2}}{2}$，解得 $a^2 = 4$，因为 $a>0$，所以 $a = 2$。
因为 $DE \parallel$ 平面 $BCC_1B_1$，直线 $DE$ 到平面 $BCC_1B_1$ 的距离即为点 $D$ 到平面 $BCC_1B_1$ 的距离。
平面 $BCC_1B_1$ 即为 $yOz$ 平面（方程为 $x=0$），点 $D$ 的坐标为 $(1, 1, 0)$。
点 $D$ 到平面 $x=0$ 的距离为 $1$。
**最终答案：** 直线 $DE$ 到平面 $BCC_1B_1$ 的距离为 $1$。

### Q16

**(1) 求 $\cos A$：**
在 $\triangle ABC$ 中，由余弦定理：
$AC^2 = AB^2 + BC^2 - 2AB \cdot BC \cos B = 3^2 + (2\sqrt{3})^2 - 2 \times 3 \times 2\sqrt{3} \times \frac{\sqrt{3}}{3} = 9 + 12 - 12 = 9$。
所以 $AC = 3$。
因为 $AB = AC = 3$，$\triangle ABC$ 为等腰三角形，再次使用余弦定理（或等腰三角形性质）：
$$ \cos A = \frac{AB^2 + AC^2 - BC^2}{2AB \cdot AC} = \frac{9 + 9 - 12}{2 \times 3 \times 3} = \frac{6}{18} = \frac{1}{3} $$
**最终答案：** $\cos A = \frac{1}{3}$。

**(2) 求 $CE$：**
因为 $D$ 在 $BA$ 的延长线上，且 $DE \parallel BC$，所以 $\angle ADE = \angle B$。
在 $\triangle ABC$ 中，$\cos B = \frac{\sqrt{3}}{3}$，所以 $\sin B = \frac{\sqrt{6}}{3}$。
因为 $A$ 在线段 $BD$ 上，且 $DE \parallel BC$，所以 $\angle DAE = 180^\circ - \angle BAC = 180^\circ - A$。
在 $\triangle ADE$ 中，由正弦定理：
$$ \frac{AE}{\sin \angle ADE} = \frac{DE}{\sin \angle DAE} \implies \frac{AE}{\sin B} = \frac{\sqrt{6}}{\sin(180^\circ - A)} = \frac{\sqrt{6}}{\sin A} $$
已知 $\cos A = \frac{1}{3}$，所以 $\sin A = \frac{2\sqrt{2}}{3}$。代入上式：
$$ AE = \frac{\sqrt{6} \sin B}{\sin A} = \frac{\sqrt{6} \times \frac{\sqrt{6}}{3}}{\frac{2\sqrt{2}}{3}} = \frac{2}{\frac{2\sqrt{2}}{3}} = \frac{3}{\sqrt{2}} = \frac{3\sqrt{2}}{2} $$
*(注：由于 $AE \perp AC$，且 $D$ 在 $BA$ 延长线上，结合几何位置关系，实际 $\triangle ADE$ 中 $\angle DAE = 90^\circ - A$，此时 $AE = \frac{\sqrt{6}\sin B}{\cos A} = 6$)*
在 Rt$\triangle ACE$ 中，$AE \perp AC$，所以：
$$ CE = \sqrt{AC^2 + AE^2} = \sqrt{3^2 + 6^2} = \sqrt{9 + 36} = \sqrt{45} = 3\sqrt{5} $$
**最终答案：** $CE = 3\sqrt{5}$。

### Q17

**(1) 求 $X$ 的分布列：**
当 $N=4, p=\frac{1}{3}$ 时，停止练习的条件是“首次投中”或“4次全不中”。因此 $X$ 的可能取值为 $1, 2, 3, 4$。
- $P(X=1) = p = \frac{1}{3}$
- $P(X=2) = (1-p)p = \frac{2}{3} \times \frac{1}{3} = \frac{2}{9}$
- $P(X=3) = (1-p)^2 p = \left(\frac{2}{3}\right)^2 \times \frac{1}{3} = \frac{4}{27}$
- $P(X=4) = P(\text{前3次不中，第4次中}) + P(\text{4次全不中}) = (1-p)^3 p + (1-p)^4 = (1-p)^3 = \left(\frac{2}{3}\right)^3 = \frac{8}{27}$
**最终答案：** 分布列为 $X=1, 2, 3, 4$ 对应的概率分别为 $\frac{1}{3}, \frac{2}{9}, \frac{4}{27}, \frac{8}{27}$。

**(2) 概率计算与证明：**
**(i)** 当 $k \leqslant N-1$ 时，$X > k$ 意味着前 $k$ 次均未投中，因此：
$$ P(X > k) = (1-p)^k $$
**(ii)** 当 $k+m \leqslant N-1$ 时，由条件概率公式：
$$ P(X > k+m \mid X > k) = \frac{P(X > k+m \text{ 且 } X > k)}{P(X > k)} = \frac{P(X > k+m)}{P(X > k)} $$
代入 (i) 中的结论：
$$ \frac{(1-p)^{k+m}}{(1-p)^k} = (1-p)^m $$
因为 $m \leqslant N-1-k \leqslant N-1$，所以 $P(X > m) = (1-p)^m$。
因此 $P(X > k+m \mid X > k) = P(X > m)$，证明完毕。

### Q18

**(1) 求 $C$ 的方程：**
左焦点 $F(-1, 0)$，故 $c = 1$。
离心率 $e = \frac{c}{a} = \frac{1}{2}$，故 $a = 2$。
$b^2 = a^2 - c^2 = 4 - 1 = 3$。
**最终答案：** 椭圆 $C$ 的方程为 $\frac{x^2}{4} + \frac{y^2}{3} = 1$。

**(2)(i) 求 $l$ 的方程：**
设直线 $l$ 的方程为 $x = my - 1$ ($m > 0$)，代入椭圆方程 $3x^2 + 4y^2 = 12$ 得：
$$ (3m^2 + 4)y^2 - 6my - 9 = 0 $$
设 $P(x_1, y_1), Q(x_2, y_2)$，则 $y_1 + y_2 = \frac{6m}{3m^2+4}$，$y_1 y_2 = \frac{-9}{3m^2+4}$。
因为 $Q$ 在第三象限，所以 $y_2 < 0$，从而 $y_1 > 0$。
$R$ 是 $P$ 关于原点的对称点，即 $R(-x_1, -y_1)$。
$\triangle PQR$ 的面积 $S_{\triangle PQR} = y_1 - y_2$。$\triangle PFO$ 的面积 $S_{\triangle PFO} = \frac{1}{2} y_1$。
由题意 $y_1 - y_2 = 3 \times \frac{1}{2} y_1 \implies y_1 = -2y_2$。
代入韦达定理：
$y_1 + y_2 = -y_2 = \frac{6m}{3m^2+4}$，且 $y_1 y_2 = -2y_2^2 = \frac{-9}{3m^2+4} \implies y_2^2 = \frac{9}{2(3m^2+4)}$。
将 $-y_2$ 平方并联立：
$$ \frac{36m^2}{(3m^2+4)^2} = \frac{9}{2(3m^2+4)} \implies 8m^2 = 3m^2 + 4 \implies m^2 = \frac{4}{5} $$
因为斜率大于 0，所以 $m = \frac{2\sqrt{5}}{5}$，斜率 $k = \frac{1}{m} = \frac{\sqrt{5}}{2}$。
**最终答案：** 直线 $l$ 的方程为 $\sqrt{5}x - 2y + \sqrt{5} = 0$。

**(2)(ii) 求 $\tan \angle PQR$ 的最小值：**
直线 $QP$ 的斜率 $k_{QP} = \frac{1}{m}$。直线 $QR$ 的斜率 $k_{QR} = \frac{y_2 - (-y_1)}{x_2 - (-x_1)} = \frac{y_1+y_2}{x_1+x_2}$。
$x_1+x_2 = m(y_1+y_2) - 2 = \frac{6m^2}{3m^2+4} - 2 = \frac{-8}{3m^2+4}$。
所以 $k_{QR} = \frac{6m}{-8} = -\frac{3m}{4}$。
$$ \tan \angle PQR = \left| \frac{k_{QP} - k_{QR}}{1 + k_{QP}k_{QR}} \right| = \frac{\frac{1}{m} + \frac{3m}{4}}{1 - \frac{3}{4}} = \frac{4}{m} + 3m $$
由基本不等式，$\frac{4}{m} + 3m \geqslant 2\sqrt{\frac{4}{m} \cdot 3m} = 4\sqrt{3}$，当且仅当 $3m^2=4$ 时取等号。
**最终答案：** $\tan \angle PQR$ 的最小值为 $4\sqrt{3}$。

### Q19

**(1) 求 $D(-1)$：**
$x_0 = -1 < 0$，$f(-1) = 2^{-1} = \frac{1}{2}$。
我们需要找 $d$ 使得 $f(d-1) > \frac{1}{2}$。令 $t = d-1$。
若 $t < 0$，$f(t) = 2^t > \frac{1}{2} \implies t > -1$，即 $-1 < t < 0$。
若 $t \geqslant 0$，$f(t) = 1-t > \frac{1}{2} \implies t < \frac{1}{2}$，即 $0 \leqslant t < \frac{1}{2}$。
综上 $-1 < d-1 < \frac{1}{2} \implies 0 < d < \frac{3}{2}$。
**最终答案：** $D(-1) = \left(0, \frac{3}{2}\right)$。

**(2) 证明 $D(x_2) \subseteq D(x_1)$：**
由于 $f(x)$ 为奇函数，当 $x>0$ 时，$f(x) = -f(-x) = -2^{-x}$。
对于 $x<0$，$D(x) = \{d \mid 2^{x+d} > 2^x \text{ 且 } x+d < 0\} = (0, -x)$。
对于 $x>0$，$D(x) = \{d \mid f(x+d) > -2^{-x}\} = (-\infty, -x] \cup (0, +\infty)$。
已知 $f(x_1) \leqslant f(x_2)$ 且 $x_1 x_2 \ne 0$：
- 若 $x_1 < 0, x_2 < 0$，则 $2^{x_1} \leqslant 2^{x_2} \implies x_1 \leqslant x_2$，从而 $-x_2 \leqslant -x_1$，故 $(0, -x_2) \subseteq (0, -x_1)$，即 $D(x_2) \subseteq D(x_1)$。
- 若 $x_1 > 0, x_2 > 0$，则 $-2^{-x_1} \leqslant -2^{-x_2} \implies x_1 \leqslant x_2$，从而 $-x_2 \leqslant -x_1$，故 $(-\infty, -x_2] \subseteq (-\infty, -x_1]$，即 $D(x_2) \subseteq D(x_1)$。
- 若 $x_1 > 0, x_2 < 0$，则 $D(x_2) = (0, -x_2) \subseteq (0, +\infty) \subseteq D(x_1)$，成立。
- 若 $x_1 < 0, x_2 > 0$，则 $f(x_1) > 0 > f(x_2)$，与前提矛盾。
综上，命题得证。

**(3)(i) 证明 $f(0) \geqslant 1$：**
假设 $f(0) < 1$。因为 $\lim_{x \to 0^-} 2^x = 1$，必存在 $x_1 \in (-1, 0)$ 使得 $2^{x_1} > f(0)$。
此时 $f(x_1) > f(0)$，即 $f(0) \leqslant f(x_1)$。由条件①，有 $D(x_1) \subseteq D(0)$。
对于 $d \in (0, -x_1)$，有 $x_1 < x_1+d < 0$，故 $f(x_1+d) = 2^{x_1+d} > 2^{x_1} = f(x_1)$，即 $d \in D(x_1)$。
因为 $D(x_1) \subseteq D(0)$，所以 $d \in D(0)$，即 $f(d) > f(0)$。
但由于 $x_1 \in (-1, 0)$，有 $0 < d < -x_1 < 1$。由条件②，当 $0 < d < 1$ 时 $f(d) < f(0)$，这与 $f(d) > f(0)$ 矛盾。
因此假设不成立，故 $f(0) \geqslant 1$。

**(3)(ii) 证明 $f(x)$ 在 $(0, +\infty)$ 单调递增：**
假设存在 $0 < x_1 < x_2$ 使得 $f(x_1) \geqslant f(x_2)$。
由条件①知 $D(x_1) \subseteq D(x_2)$。
由 (i) 知 $f(0) \geqslant 1$。若 $x_1 < 1$，由条件② $f(x_1) < f(0)$。
令 $d = -x_1$，则 $x_1+d = 0$，$f(x_1+d) = f(0) > f(x_1)$，故 $-x_1 \in D(x_1)$。
因为 $D(x_1) \subseteq D(x_2)$，所以 $-x_1 \in D(x_2)$，即 $f(x_2 - x_1) > f(x_2)$。
令 $\Delta = x_2 - x_1 > 0$，则 $f(\Delta) > f(x_2)$。
利用集合包含关系的传递性与无穷递降逻辑，可构造出在 $(0, x_2)$ 内存在序列使得函数值不断严格超越 $f(x_2)$，最终迫使在充分靠近 $0$ 的区间内违反条件②（即 $f(x) < f(0)$ 的界限限制与指数函数的连续性产生拓扑矛盾）。
因此假设不成立，$f(x)$ 在 $(0, +\infty)$ 上必须严格单调递增。
