### Q06 · 5 pts

**ZH.** 一百零八塔位于宁夏回族自治区青铜峡市，以其独特的建筑格局和深厚的历史文化闻名遐迩。该塔群共有 $108$ 座塔，依山势自上而下排成 $12$ 行，将第 $i$ 行中塔的座数记为 $a_i\;(i = 1, 2, \cdots, 12)$，其中 $a_1=1$，$a_2=a_3=3$，$a_4=a_5=5$，且 $a_6, a_7, \cdots, a_{12}$ 是一个首项为 $7$，公差为 $2$ 的等差数列。将 $a_1, a_2, \cdots, a_{12}$ 分为 $6$ 组，每组 $2$ 个数，使得每组的 $2$ 个数之和可构成一个项数为 $6$ 且公差为 $d\;(d > 0)$ 的等差数列，则 $d =$

|:---:|:--------|
| A | $2$ |

### Q08 · 5 pts

**EN.** Let $U$ be the set of $64$ points $(x_1,x_2,x_3)$ with each coordinate in $\{-2,-1,1,2\}$, and $P=(1,1,1)$. Let $\Omega = U\setminus\{P\}$. A point is drawn uniformly from $\Omega$. For $A(x_1,x_2,x_3)\in\Omega$, define $X(A)=x_1+x_2+x_3$. Find the expected value $E(X)$.

**ZH.** 设 $U = \{(x_1, x_2, x_3) \mid x_i \in \{-2, -1, 1, 2\},\ i = 1, 2, 3\}$ 为空间中 $64$ 个点构成的集合，点 $P(1, 1, 1)$。记样本空间 $\Omega = \complement_{U}\{P\}$。从 $\Omega$ 中随机取一个点，定义随机变量 $X$ 如下：对 $\Omega$ 中的每个点 $A(x_1, x_2, x_3)$，令 $X(A) = x_1 + x_2 + x_3$，则 $X$ 的数学期望为

| Opt | Content |
|:---:|:--------|
| A | $-\dfrac{1}{21}$ |
| B | $-\dfrac{1}{63}$ |
| C | $0$ |
| D | $\dfrac{1}{7}$ |

**Answer:** **A**

**Solution sketch | 要点**

**EN.** Coordinate values $\{-2,-1,1,2\}$ are symmetric about $0$ $\Rightarrow$ $\sum_{U}X=0$; deleting $P(1,1,1)$ with $X(P)=3$ leaves $\sum_{\Omega}X=-3$ over $63$ points $\Rightarrow$ $E(X)=-\dfrac{1}{21}$.  
**ZH.** 坐标取值 $\{-2,-1,1,2\}$ 关于 $0$ 对称 $\Rightarrow$ $U$ 上 $X$ 总和为 $0$；去掉 $X(P)=3$ 的点 $P(1,1,1)$ 后，$\Omega$ 上总和 $-3$、共 $63$ 点 $\Rightarrow$ $E(X)=-\dfrac{3}{63}=-\dfrac{1}{21}$。

### Q10 · 6 pts

**EN.** In space, $A$ and $B$ are fixed. Moving point $C$ has distance $2$ from line $AB$; moving point $D$ has distance $1$ from line $AB$. If the dihedral angle $C\text{-}AB\text{-}D$ is $60^\circ$, which statements hold?

**ZH.** 在空间中，$A$，$B$ 为两个定点，动点 $C$ 到直线 $AB$ 的距离为 $2$，动点 $D$ 到直线 $AB$ 的距离为 $1$。若二面角 $C\text{-}AB\text{-}D$ 为 $60^\circ$，则

| Opt | Content |
|:---:|:--------|
| A | $\angle CAD \geqslant 60^\circ$ |
| B | $CD \geqslant \sqrt{3}$ |
| C | 当 $AB \perp CD$ 时，$CD \perp$ 平面 $ABD$ |
| D | 当 $AB \perp$ 平面 $ACD$ 时，$AC \perp AD$ |

| Opt | Content (EN) |
|:---:|:--------|
| C | If $AB \perp CD$, then $CD \perp$ plane $ABD$ |

D: $AB\perp$ plane $ACD$ makes $\angle CAD$ equal the $60^\circ$ dihedral, not $90^\circ$ — false.  
**ZH.** A：$C,D$ 沿 $AB$ 方向拉开可使 $\angle CAD\to0$，错。B：$CD$ 的跨半平面分量恒定，$CD^2=\Delta^2+3\geqslant3$，对。C：$AB\perp CD$ 时轴向分量为零，$CD$ 与平面 $ABD$ 的法向平行，对。D：$AB\perp$ 平面 $ACD$ 时 $\angle CAD$ 即二面角 $60^\circ\ne90^\circ$，错。

### Q11 · 6 pts

**EN.** Unit circles $C_1$, $C_2$, $C_3$ are as given. Line $l\colon y=kx+b$ meets each circle at two distinct points. Let $s_1,s_2,s_3$ be the chord lengths inside $C_1,C_2,C_3$. Which statements hold?

**ZH.** 已知圆 $C_1\colon (x+1)^2 + y^2 = 1$，圆 $C_2\colon (x-1)^2 + y^2 = 1$，圆 $C_3\colon x^2 + (y-\sqrt{3})^2 = 1$，直线 $l\colon y = kx + b$ 与 $C_1, C_2, C_3$ 均有两个交点。记 $l$ 被 $C_1, C_2, C_3$ 截得的弦长分别为 $s_1, s_2, s_3$，则

| Opt | Content |
|:---:|:--------|
| A | $k$ 可以取任意实数 |
| B | 满足 $s_1 = s_2 = s_3$ 的直线 $l$ 共有 3 条 |
| C | 满足 $s_1 + s_2 + s_3 = 3$ 的直线 $l$ 多于 3 条 |
| D | 当 $b = 0$ 时，$s_1 + s_2 + s_3$ 的最大值为 $\dfrac{2\sqrt{21}}{3}$ |

| Opt | Content (EN) |
|:---:|:--------|
| A | $k$ can be any real number |
| B | Exactly 3 lines satisfy $s_1=s_2=s_3$ |
| C | More than 3 lines satisfy $s_1+s_2+s_3=3$ |
| D | If $b=0$, then $\max(s_1+s_2+s_3)=\dfrac{2\sqrt{21}}{3}$ |

**Answer:** **BCD**

**Solution sketch | 要点**

**EN.** Centers $(\pm1,0),(0,\sqrt3)$, pairwise distance $2$. A: a feasible $b$ exists iff $\sqrt3+|k|<2\sqrt{k^2+1}\iff(\sqrt3|k|-1)^2>0$, so $k\ne\pm\dfrac{\sqrt3}{3}$ — false. B: $s_1=s_2=s_3\iff$ equal center distances $\iff$ the three mid-parallels of the center triangle, each at $d=\dfrac{\sqrt3}{2}<1$ — exactly $3$, true. C: those $3$ lines already give $s_1+s_2+s_3=3$ and the level set extends to a curve — more than $3$, true. D: $b=0$: $S=\dfrac{4}{\sqrt{k^2+1}}+2\sqrt{\dfrac{k^2-2}{k^2+1}}$ $(k^2>2)$, maximized at $k^2=\dfrac{17}{4}$: $S_{\max}=\dfrac{14}{\sqrt{21}}=\dfrac{2\sqrt{21}}{3}$ — true.  
**ZH.** 圆心 $(\pm1,0),(0,\sqrt3)$ 两两距离 $2$。A：$b$ 可行 $\iff\sqrt3+|k|<2\sqrt{k^2+1}\iff(\sqrt3|k|-1)^2>0$，即 $k\ne\pm\dfrac{\sqrt3}{3}$，错。B：弦长相等 $\iff$ 圆心距相等 $\iff$ 中心三角形的三条中位平行线（$d=\dfrac{\sqrt3}{2}<1$），恰 $3$ 条，对。C：该 $3$ 条已满足 $s_1+s_2+s_3=3$，且水平集延拓为曲线，多于 $3$ 条，对。D：$b=0$ 时 $S=\dfrac{4}{\sqrt{k^2+1}}+2\sqrt{\dfrac{k^2-2}{k^2+1}}$（$k^2>2$），于 $k^2=\dfrac{17}{4}$ 取 $S_{\max}=\dfrac{2\sqrt{21}}{3}$，对。

### Q13 · 5 pts

**EN.** Given $f(x) = 2\sin(ax + \theta)$ ($a \in \mathbf{Z}$, $0 \leqslant \theta < 2\pi$) is an even function and is strictly increasing on $\left(0, \dfrac{\pi}{2}\right)$, find $\theta$ and $f\!\left(\dfrac{2\pi}{3}\right)$.

**ZH.** 已知 $f(x) = 2\sin(ax + \theta)\;(a \in \mathbf{Z},\ 0 \leqslant \theta < 2\pi)$ 是偶函数，$f(x)$ 在区间 $\left(0, \dfrac{\pi}{2}\right)$ 单调递增，则 $\theta =$ __________，$f\!\left(\dfrac{2\pi}{3}\right) =$ __________．

**Solution sketch | 要点**

**ZH.** 偶函数 $\Rightarrow\theta\in\left\{\dfrac{\pi}{2},\dfrac{3\pi}{2}\right\}$；$\theta=\dfrac{\pi}{2}$ 时 $f=2\cos ax$ 在 $\left(0,\dfrac{\pi}{2}\right)$ 不增，舍 $\Rightarrow\theta=\dfrac{3\pi}{2}$，$f=-2\cos ax$；单调性限定 $a\in\{\pm1,\pm2\}$，均得 $f\!\left(\dfrac{2\pi}{3}\right)=1$。

### Q14 · 5 pts

**EN.** Suppose there exists a sequence $\{a_n\}$ such that for all $n \in \mathbf{N}^*$, $a_1+\cdots+a_{3n}=n^2+n$, and some nine consecutive terms form a geometric progression with ratio $q$. Find the maximum possible value of $q$.

**ZH.** 设实数 $q$ 满足：存在数列 $\{a_n\}$，使得对于任意 $n \in \mathbf{N}^*$，均有 $a_1 + a_2 + \cdots + a_{3n} = n^2 + n$，且 $\{a_n\}$ 中有某些连续 $9$ 项 $a_k, a_{k+1}, \cdots, a_{k+8}$ 是公比为 $q$ 的等比数列，则 $q$ 的最大值为 __________．

**Answer:** $\sqrt[3]{\dfrac{3}{2}}=\dfrac{\sqrt[3]{12}}{2}$

**Solution sketch | 要点**

**EN.** $S_{3n}=n^2+n\Rightarrow$ aligned triple blocks satisfy $B_m=a_{3m-2}+a_{3m-1}+a_{3m}=2m$. A $9$-term GP window covers $3$ full blocks (start $\equiv1\bmod3$) or $2$. Three blocks force $(m+2)^2=(m+1)(m+3)$ — impossible; two blocks give $q^3=\dfrac{m+3}{m+2}$ $(m\geqslant0)$, maximal at $m=0$: $q^3=\dfrac{3}{2}$. Partial blocks are absorbed by free terms $\Rightarrow q_{\max}=\sqrt[3]{3/2}$.  
**ZH.** $S_{3n}=n^2+n\Rightarrow$ 对齐三元块和 $B_m=2m$。$9$ 个连续项含 $3$ 个整块（起点 $\equiv1\pmod3$）或 $2$ 个整块：$3$ 块致 $(m+2)^2=(m+1)(m+3)$ 矛盾；$2$ 块给 $q^3=\dfrac{m+3}{m+2}$（$m\geqslant0$），$m=0$ 时最大：$q^3=\dfrac{3}{2}$；残块由自由项吸收 $\Rightarrow q_{\max}=\dfrac{\sqrt[3]{12}}{2}$。
