## Build | 编译

```bash
# English · pdfLaTeX
cd paper/en  && latexmk -pdf main.tex        # or: pdflatex main.tex (×2)

# 中文 · XeLaTeX（需 ctex 宏包）
cd paper/zh  && latexmk -xelatex main_zh.tex # or: xelatex main_zh.tex (×2)
```

No local TeX? Upload the folder to [Overleaf](https://www.overleaf.com):
**Menu → Compiler** = pdfLaTeX for `en/`, XeLaTeX for `zh/`.
无本地 TeX 时上传 Overleaf；`en/` 选 pdfLaTeX，`zh/` 选 XeLaTeX。

Search both `.tex` files for bracketed placeholders:
两份 `.tex` 中的占位符（全文检索 `[` 即可定位）：

- `[email]` — contact · 联系邮箱
- `[REPO-URL]` — public repository URL (appears twice per file) · 仓库地址

## arXiv checklist | arXiv 投稿清单

arXiv accepts **English** manuscripts only — submit `en/`; the `zh/`
version is for domestic preprint/blog distribution.
arXiv 仅收英文稿——提交 `en/`；中文稿用于国内预印本或博客分发。

1. Bundle: `en/main.tex` + `en/ncee2026_results_paper.png` (flat zip, no folders).
2. License: **CC BY 4.0** recommended.
3. Primary category: **cs.AI**; cross-list: **cs.CY** (Computers and Society).
4. Abstract field: paste the abstract text (plain text, `$...$` math allowed).
5. Compile check on arXiv: pdfLaTeX, TeX Live — both files use standard
   packages only (`geometry`, `booktabs`, `graphicx`, `amsmath`, `hyperref`,
   `caption`, `enumitem`, `microtype`, `xcolor`, `lmodern`).
